# 🎯 C++ Quiz Application

A lightweight, interactive console-based Quiz App built using **C++**. The application presents multiple-choice questions, validates user inputs (case-insensitive), tracks points, and displays the final score.

---

## 🌟 Features
* **Case-Insensitive Inputs:** Accepts answers in both uppercase and lowercase (e.g., `B` or `b`).
* **Instant Feedback:** Tells the user immediately whether the answer is correct or wrong.
* **Score Tracker:** Dynamically tracks and displays the total score at the end.

---

## 🛠️ Tech Stack
* **Language:** C++
* **Standard:** C++11 or higher
* **Compiler:** GCC / Clang / MSVC
